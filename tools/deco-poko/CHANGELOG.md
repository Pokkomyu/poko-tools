# CHANGELOG

## 1.5.0 (2026-10-25)
- 艶ペンを軽くした(ぶらんち「重いね。線を引いてる途中以上にカクつく」)。見た目はそのまま
  - 光の計算を縮小した画像で行い(細い線は縮小を弱め、計算する画素の数に上限)、陰影だけを引き伸ばして元の解像度の形で切り抜く
  - 描いている途中の表示は 1 フレーム 1 回だけ作る(マウスや指の動きごとに作らない)
  - 手元の計測(ヘッドレスの Chrome): 長い線 1 フレーム 58ms → 15ms、塗りつぶし 138ms → 36ms、戻す 220ms → 43ms
- 水彩をゼロから作り直した(ぶらんち「全然だめ、ゼロからやり直して」)。乾いた水彩の特徴: 輪郭はくっきりで太さがゆっくり揺れ、中は薄くむらがあり、縁は顔料が集まってくっきり濃い。紙の目と筆の毛のかすかな筋。1 本の中では濃くならず、重ね塗りで濃くなる

## 1.4.0 (2026-10-25)
- 艶ペンの光を形から計算するようにした(ぶらんち「ぐりぐり塗りつぶしたときに演算しなおすべき。光源の位置や絵の具の載せ方の向きを考えたらわかるはず」)。続けて描いた艶をまとめて 1 つの立体として、高さ(縁の丸み + 塗りつぶした塊のなだらかな山 + 描いた線の芯の盛り上がり)から面の向きを求め、左上の光で明るさとツヤを決める。ツヤは光の反射が目に入る面だけに、ところどころ出る
- 水彩を作り直した(ぶらんち「全然ダメ。類似のサンプルを Web 検索して見直して」)。Tyler Hobbs の方法: 線の輪郭を少しずつ崩したごく薄い層を 30 枚重ね、縁のにじみと塗りむらを出す。縁の溜まりと紙の目を足す
- クレヨンを追加(ぶらんち「ちょっとモケモケしてる感じ」)。紙の目でぼそぼそ抜けて、縁がふわっとする
- 線ごとの乱数・紙の目の乱数の計算が JavaScript の数の精度を超えて偏っていたのを直した(32 bit のかけ算に)

## 1.3.0 (2026-10-24)
- 艶ペンを作り直した(ぶらんちの見本: ケチャップのような線)。ぷっくりした形の下側の縁に影、ところどころに白いツヤ、線の外にうっすら影。続けて描いた艶(色・フチが同じ間)は 1 つの形として扱い、重なった所も形に合わせて影とツヤを計算し直す
- 水彩を作り直した(ぶらんちの見本: 筆で塗った水彩)。薄い下地の上に筆の毛の筋を重ね、縁と端はかすれる。重ねると濃くなる
- 水彩にもフチを付けられるようにした。水彩を選ぶたびにフチ幅は 0 に戻り、上げればフチが付く(半透明なので、フチは輪にして下に敷く)

## 1.2.1 (2026-10-24)
- 色を変えて上に重ねたフチ付きの線(ペン・艶・マーカー)のフチが、先の線の下に回っていたのを直した(ぶらんち報告)。続けて描いた線のフチをまとめるのは、色・フチ色・フチ幅が同じ間だけにした。同じ色で書いた文字は今まで通りフチがまとまり、あとの線のフチで先の線が切れない

## 1.2.0 (2026-10-24)
- 消しゴムを 2 種類にした(2026-10-24 ぶらんち。iOS と同じ)。「消し方」で選ぶ
  - ピクセル: 今までの消しゴム(なぞった所だけ消す)
  - オブジェクト: 触れた線を 1 本まるごと消す。選んでいるレイヤーの線だけ。なぞって何本かまとめて消せて、戻す 1 回で全部戻る
- 線の記録も保存するようにした。読み込み直しても、最近描いた 100 本までは線ごと消せる(それより古い線と、1.2 より前の保存の絵は画像なので消せない)。保存の容量が足りないときは今まで通り画像だけで保存する
- スポイト: 色の四角の下と小パレットに追加。Chrome / Edge では画面のどこでも拾える。使えない所(OBS の対話ウィンドウ・Firefox など)ではボードを触った所の色を拾う
- 小パレットの色見本は 15 個まで(16 個目にスポイト)

## 1.1.1 (2026-10-24)
- 続けて描いた艶ペンが、交わる所でフチ付きのペンと同じく 1 本になじむようにした(ぶらんち報告)。今までは線ごとに重ねていたので、あとの線の影が先の線のツヤを消していた。続く間は フチ → 線 → 影 → ツヤ の順にまとめて描き、影とツヤは交わる所でも二重に濃くならない。普通のペン・マーカーなどほかの道具・消しゴム・消去・不透明度の変更で区切る

## 1.1.0 (2026-10-24)
- 「縁取り」をやめて、ペン・艶・マーカーの「フチ幅」にまとめた(2026-10-24 ぽこ)。フチ幅 0 はフチなし、上げるとフチが付く。フチ幅は道具ごとに覚える
  - 続けて描いたフチ付きの線は、今まで通りフチをまとめる(マーカーも、続けて描いた線どうしのフチは中に出ない)
  - フチ付きのマーカーは、マーカーの下にフチ色が透けないよう、フチを輪の形にして敷く
  - 1.0.x で縁取りを選んでいた人は、ペン+そのときのフチ幅で開く。ほかの道具を選んでいた人はフチ幅 0(今までのペンにいきなりフチが付かない)
- 艶ペン: 線の上側に白いツヤ、下側に少し濃い影を、線の形の中だけに重ねる(光は左上から)
- 水彩: ふちがにじんだ薄い色に、ふちに溜まった濃い色とむらのある紙の目を足す。1 本の中では濃くならず、別の線と重ねると濃くなる
- 道具の並びを ペン / 艶 / マーカー / ネオン / 水彩 / 消しゴム にした(小パレットも同じ)
- 画面の右下に出る版の表示が 1.0.0 のままだったのを直した

## 1.0.1 (2026-10-17)
- ネオンを続けて描くと、光がまとまって 1 本のネオン管のようになじむようにした(縁取りのフチと同じ「まとまり」)。今までは線ごとに光を上に重ねていたので、あとの線の光が先の線の芯にかぶり、画数の多い字ほど線が埋もれて読みにくかった。まとまりの中では 光 → 線 → 芯 の順に描くので、芯はどの線も上に出る。普通のペン・縁取り・マーカー・消しゴム・消去を挟むとそこで区切る。1 本だけの見た目は今まで通り

## 1.0.0 (2026-10-17)
- プラス版にあったペンと操作を無料版にも入れた(2026-10-16 ぽこ決定。一緒にデコるはプラス版の Web 版だけのまま)
  - ネオンペン: 線の色で周りが光り、中心は白っぽい芯になる
  - マーカーペン: 半透明で平たい(チゼル型)ペン先。横に引くと太く、縦に引くと細い。続けて描いても重なりが濃くならない。濃さはマーカーを選んでいる間の「不透明」スライダーで変える(初期 40%)
  - 縁取りのフチ色に「自由」を追加(自動 / 白 / 黒 / 自由)
  - 画面に出る小パレット: 画面を右クリック(スマホ・タブレットは長押し)すると、その場に色とペンの切り替えが出る。指やペンは動かし始めてから線になる(タップは今まで通り点)
- パネルが画面に収まらないときはパネルの中をスクロールできるようにした

## 0.1.0 (2026-10-15)
- 配信画面に重ねて描けるお絵かきボードを追加(ペン / 縁取り / 消しゴム、レイヤー 3 枚、戻す / やり直す)
- ペンの色はパネル内のピッカーで選ぶ。OBS の対話ウィンドウでブラウザ標準の色選択が当てにならないため
