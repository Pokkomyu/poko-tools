# CHANGELOG

## 0.2.1 (2026-10-16)
- 縁取りを続けて描くと、フチがまとまって 1 つの縁取りになるようにした(文字を書いたとき、あとの線のフチが先の線を切らない)。普通のペン・消しゴム・消去を挟むとそこで区切り、その後の縁取りは前の絵の上に重なる(0.1.1 の修正はそのまま)

## 0.2.0 (2026-10-15)
- 戻す / やり直すを、描いた操作の記録から描き直す方式にした(見た目と操作は同じ)。戻せる回数を 20 回から 100 回に増やした
- 「このレイヤーを消す」「全部消す」も 1 回の操作として戻せる(今まで通り)
- 再読み込みした後は、読み込んだ絵より前には戻せない(今まで通り)

## 0.1.1 (2026-10-15)
- 縁取りペンで先に描いた線の上に描くと、描き終わった瞬間にフチだけ先の線の下に回っていたのを直した。縁取りは線 1 本ごとに「フチ+線」をまとめて重ねる(描いている途中と同じ見た目のまま確定する)
- 0.1.0 で保存した絵は、そのときの見た目のまま読み込む

## 0.1.0 (2026-10-15)
- 配信画面に重ねて描けるお絵かきボードを追加(ペン / 縁取り / 消しゴム、レイヤー 3 枚、戻す / やり直す)
- ペンの色はパネル内のピッカーで選ぶ。OBS の対話ウィンドウでブラウザ標準の色選択が当てにならないため
- 縁取りのフチ色は 自動 / 白 / 黒。自動はペンの明るさで白か黒を選ぶ(白ペン+白フチで太い白線になるのを防ぐ)
- 色の履歴には実際に描いた色だけが入る。ほぼ同じ色は新しい方に置き換え、右クリックで削除できる
- キー操作は Tab(UI を隠す / 出す)だけ
- URL に `?id=名前` を付けると保存先を分けられる(同じボードを複数置くとき)
