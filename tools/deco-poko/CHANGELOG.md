# CHANGELOG

## 1.0.1 プラス (2026-10-17)
- 無料版 1.0.1 を取り込んだ。続けて描いたネオンの光がまとまり、あとの線の光が先の線の芯にかぶらなくなった(画数の多い字が読みやすくなる)。一緒にデコるでも同じ描き方になる

## 1.0.0 プラス (2026-10-17)
- 無料版 1.0.0 を取り込んだ。ネオン・マーカー・フチ色の自由・小パレットは無料版にも入ったので、プラス版だけの機能は一緒にデコる(hoshino-poko.com の Web 版)になった。見た目と操作は 0.5.1 プラスと同じ

## 0.5.1 プラス (2026-10-16)
- マーカーペンのペン先を平たい(チゼル型)にした。横に引くと太く、縦に引くと細く、線の端は斜めに切れる(ぽこの見本)。半透明で重ねても濃くならないのは今まで通り
- マーカーの濃さを選べるようにした。マーカーを選んでいる間は「不透明」スライダーがマーカーの濃さ(初期 40%、ペンの不透明度とは別に覚える)。濃さが同じマーカーが続く間は重ねても濃くならない
- 画面の小パレットの幅を少し広げ、ペンの名前が折り返さないようにした

## 0.5.0 プラス (2026-10-16)
- ネオンペン: 線の色で周りが光り、中心は白っぽい芯になる
- マーカーペン: 半透明(40%)。続けて描いたマーカーは重ねても濃くならない(普通のペン・ネオン・消しゴム・消去を挟むとそこで区切る)
- 縁取りのフチ色に「自由」を追加(自動 / 白 / 黒 / 自由)。自由を押すとフチの色を選べる
- 画面に出る小パレット: 画面を右クリック(スマホ・タブレットは長押し)すると、その場に色とペンの切り替えが出る
  - 指やペンは動かし始めてから線になる(長押しで点が残らないように)。タップは今まで通り点を描く
- 一緒にデコる中もネオン・マーカーが相手に届く(サーバーの新しい版が必要)

## 0.4.0 プラス (2026-10-16)
- 一緒にデコるを 3 人以上で使えるようにした(ホスト + ゲスト 3 人まで)。招待 URL は今まで通り 1 本を共有し、ゲストは人ごとの席に入る
  - 戻す / やり直す / 「全部消す(自分の線だけ)」が人ごとに分かれる(今までは同じ招待 URL の人どうしで共有していた)
  - パネルに自分の席(「ゲスト 2 で参加中」)と参加人数を出す
  - ゲストには「自分の OBS 用リンク」を出す。これを自分の OBS に貼ると、ブラウザと OBS が同じ席になる
  - 4 人を超えると「人数がいっぱいです」と出て、空いたら自動でつながる
- 無料版 0.2.2 を取り込んだ: 2 本指で触ると指の間が線でつながっていたのを直した(描くのは最初に触れた指だけ)
- 一緒にデコる中にスマホを縦向きにしていると、横向きにすると大きく描けると案内を出す
- サーバー(ぽこにゃー)の新しい版が必要。古い版のサーバーに当たったときは今まで通りの 2 人用でつながる

## 0.3.1 プラス (2026-10-16)
- 無料版 0.2.1 を取り込んだ: 縁取りが続く間はフチをまとめる(普通のペン・消しゴム・消去で区切る)。一緒にデコる中の描き直しも同じ描き方

## 0.3.0 プラス (2026-10-15)
- 有償版「デコポコ プラス」の最初の版。無料版 0.2.0 の内容を含む
- 一緒にデコる(2 人で同じ画面に描く)を追加。hoshino-poko.com の Web 版(/tools/plus/deco-poko/ と OBS 用 URL)だけで使える。ダウンロード版では出ない
  - ホストはブラウザ版で部屋を開き、招待 URL をゲストに渡す。OBS 用 URL の画面は部屋が開くと自動で参加する
  - 戻す / やり直すは自分の線だけ。ゲストの「全部消す」は自分の線だけ、ホストのは全員の線
  - 一緒にデコる中は 1920x1080 の画面として描く(ウィンドウの大きさが違っても同じ位置になる)。描いた絵はサーバーに保存しない
  - 部屋を閉じると、1 人で描いていた絵に戻る

## 0.2.2 (2026-10-16)
- スマホやタブレットで 2 本指で触ると、指と指の間が線でつながっていたのを直した。描くのは最初に触れた指だけで、描いている間の 2 本目以降の指は無視する(拡大縮小はできない)

## 0.2.1 (2026-10-16)
- 縁取りを続けて描くと、フチがまとまって 1 つの縁取りになるようにした(文字を書いたとき、あとの線のフチが先の線を切らない)。普通のペン・消しゴム・消去を挟むとそこで区切り、その後の縁取りは前の絵の上に重なる(0.1.1 の修正はそのまま)

## 0.2.0 (2026-10-15)
- 戻す / やり直すを、描いた操作の記録から描き直す方式にした(見た目と操作は同じ)。戻せる回数を 20 回から 100 回に増やした
- 「このレイヤーを消す」「全部消す」も 1 回の操作として戻せる(今まで通り)
- 再読み込みした後は、読み込んだ絵より前には戻せない(今まで通り)

## 0.1.1 (2026-10-15)
- 縁取りペンで先に描いた線の上に描くと、描き終わった瞬間にフチだけ先の線の下に回っていたのを直した。縁取りは線 1 本ごとに「フチ+線」をまとめて重ねる(描いている途中と同じ見た目のまま確定する)
- 0.1.0 で保存した絵は、そのときの見た目のまま読み込む

## 0.1.0 (2026-10-15)
- 配信画面に重ねて描けるお絵かきボードを追加(ペン / 縁取り / 消しゴム、レイヤー 3 枚、戻す / やり直す)
- ペンの色はパネル内のピッカーで選ぶ。OBS の対話ウィンドウでブラウザ標準の色選択が当てにならないため
- 縁取りのフチ色は 自動 / 白 / 黒。自動はペンの明るさで白か黒を選ぶ(白ペン+白フチで太い白線になるのを防ぐ)
- 色の履歴には実際に描いた色だけが入る。ほぼ同じ色は新しい方に置き換え、右クリックで削除できる
- キー操作は Tab(UI を隠す / 出す)だけ
- URL に `?id=名前` を付けると保存先を分けられる(同じボードを複数置くとき)
