デコポコ プラス 使い方
======================

配信画面の上に、ペンで書き込んだり縁取り文字を描いたりできるお絵かきボードです。

■ OBS で使う
  1. ソースの「+」→「ブラウザ」を追加
  2. 「ローカルファイル」にチェックを入れて index.html を選ぶ
     (ブラウザ版を使う場合はチェックを外して URL を貼る)
  3. 幅 1920 / 高さ 1080 にする
     (ブラウザで開くと背景が市松模様に見えますが、OBS では透明になります)
  4. 描いた絵がシーン切り替えで消える場合は
     「シーンがアクティブになったときにブラウザを更新」をオフにする
  描くときはソースを右クリック →「対話」で開くウィンドウの中で描きます。

■ パネル
  右下の丸いボタンをクリックで開く / 閉じる。ドラッグで場所を動かせます。
  パネルは配信にも映ります。描き終わったら Tab キー(または「UIを隠す」)で隠してください。
  もう一度 Tab で出てきます。

■ 道具
  ペン     … ふつうの線
  艶       … ツヤのある線。線の上側に白いツヤ、下側に少し濃い影が付きます
  マーカー … 半透明で平たいペン先のペン。横に引くと太く、縦に引くと細い。続けて描いても重なりが濃くならない
             濃さは、マーカーを選んでいる間の「不透明」スライダーで変えられます(最初は 40)
  ネオン   … 線の色で光るペン
  水彩     … ふちがにじんだ薄い色。1 本の中では濃くならず、別の線と重ねると濃くなります
  消しゴム … 選んでいるレイヤーだけ消す
  太さ / 不透明 … スライダーで変える

■ フチ(ペン・艶・マーカー)
  「フチ幅」を 0 より大きくすると、その道具の線にフチが付きます。0 に戻すとフチなし。
  フチ幅はペン・艶・マーカーごとに覚えます(ペンだけフチ付き、など)。
  続けて描いたフチ付きの線は、フチがまとまって 1 つの縁取りになります(文字を書いても先の線が切れない)。
  ネオン・水彩・消しゴムにはフチは付きません(選んでいる間はフチの欄が薄くなります)。
  ※ 1.0 までの「縁取り」は、ペンのフチ幅を上げたものと同じです。縁取りを選んでいた人は、ペン+そのフチ幅で開きます

■ 色
  「色」の四角を押すとパネルの中に色選びが開きます。#ff7fb3 のように色コードでも入れられます。
  フチの色は 自動 / 白 / 黒 / 自由 から選びます。自動はペンが明るい色なら黒、暗い色なら白のフチになります。
  「自由」を押すと、パネルの中でフチの色を選べます。
  丸い色見本は押すだけで切り替わります。
  「履歴」には実際に描いた色が新しい順に 8 個まで入ります。いらない色は右クリックで消せます。

■ 小パレット
  画面を右クリック(スマホ・タブレットは長押し)すると、その場に小さなパレットが出ます。
  色を押すとその色になって閉じます。上の段でペンも切り替えられます。パレットの外を触ると閉じます。
  指やペンでは、動かし始めてから線になります(長押しで点が残らないように)。タップすると点が描けます。

■ レイヤー
  1 / 2 / 3 … 押したレイヤーに描く。左の丸で表示 / 非表示
  このレイヤーを消す / 全部消す … 消したあとも「戻す」で戻せます(100 回まで)

■ 同じボードを 2 つ以上置くとき
  ローカルファイル版は、どのソースも同じ保存場所を使うので絵や履歴が混ざります。
  URL の最後に ?id=好きな名前 を付けると別々に保存されます(ブラウザ版の URL でも同じ)。

■ キーボード
  使えるのは Tab(UI を隠す / 出す)だけです。
  描いたものを戻すときは、パネルの「戻す」ボタンを押してください。
  (OBS の対話ウィンドウでキーボードの「元に戻す」を押すと、OBS 本体の操作が戻ってしまいます)

■ 一緒にデコる(hoshino-poko.com の Web 版だけ)
  2 人で同じ画面に描けます。ダウンロードした zip やローカルファイルでは使えません。
  ホスト(配信する人):
    1. ブラウザで https://hoshino-poko.com/tools/plus/deco-poko/ を開き、パネルの「一緒にデコる(部屋を開く)」を押す
    2. 出てきた招待 URL を「コピー」して、ゲストに渡す(Discord の DM など)
    3. OBS には /tools/plus/ で発行した OBS 用 URL を貼っておく。部屋が開いていると自動でつながります
  ゲスト:
    招待 URL をブラウザで開くか、OBS のブラウザソースに貼る(幅 1920 / 高さ 1080)。描くのは「対話」から
  ・戻す / やり直すは自分の線だけ。ゲストの「全部消す」は自分の線だけ消えます
  ・パネルの「一緒に」の行に、つながっているか・相手がいるかが出ます
  ・「招待をやり直す」と古い URL は使えなくなり、つながっているゲストは切れます(URL が漏れたとき用)
  ・「部屋を閉じる」と描いた絵は消え、1 人で描いていた絵に戻ります(2 回押すと実行)
  ・描いた絵はサーバーに保存しません。サーバーの更新などで切れたときは自動でつなぎ直し、絵は空になります
  ・ゲストは 3 人まで入れます(ホストと合わせて 4 人)。招待 URL は同じものを全員に渡してください
    戻す / やり直す / 全部消す(自分の線だけ)は人ごとに分かれます
  ・ゲストが自分の OBS でも描くときは、パネルの「自分のOBS用」でコピーしたリンクを OBS に貼ってください
    (招待 URL をそのまま貼ると、別の人として 1 人分の席を使います)
    このリンクには自分の席の鍵が入っています。配信画面に映したり、他の人に渡したりしないでください
  ・人数がいっぱいのときは「人数がいっぱいです」と出ます。誰かが抜けると自動でつながります
    (線を描いた人が抜けた場合は、戻ってこられるように 10 分間は席を空けておきます)
  ・同じブラウザで招待 URL を開き直した人は、同じ人として扱います。
    1 台の PC で何人分か試すときは、シークレットウィンドウや別のブラウザで開いてください
