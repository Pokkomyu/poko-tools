デコポコ 使い方
================

配信画面の上に、ペンで書き込んだり縁取り文字を描いたりできるお絵かきボードです。

■ OBS で使う
  1. ソースの「+」→「ブラウザ」を追加
  2. 「ローカルファイル」にチェックを入れて index.html を選ぶ
     (ブラウザ版を使う場合はチェックを外して URL を貼る)
  3. 幅 1920 / 高さ 1080 にする
     (ブラウザで開くと背景が市松模様に見えますが、OBS では透明になります)
  4. 描いた絵がシーン切り替えで消える場合は
     「シーンがアクティブになったときにブラウザを更新」をオフにする
  描くときはソースを右クリック →「対話」で開くウィンドウの中で描きます。

■ パネル
  右下の丸いボタンをクリックで開く / 閉じる。ドラッグで場所を動かせます。
  パネルは配信にも映ります。描き終わったら Tab キー(または「UIを隠す」)で隠してください。
  もう一度 Tab で出てきます。

■ 道具
  ペン     … ふつうの線
  艶       … ぷっくりした線。光(左上)に向いた面は明るく、反対側は暗く、ところどころに白いツヤが付きます。
             重ねて描いたり塗りつぶしたりした所は、全体を 1 つの立体として光の当たり方を計算します
  マーカー … 半透明で平たいペン先のペン。横に引くと太く、縦に引くと細い。続けて描いても重なりが濃くならない
             濃さは、マーカーを選んでいる間の「不透明」スライダーで変えられます(最初は 40)
  ネオン   … 線の色で光るペン
  水彩     … 筆で塗った水彩。ゆっくり引くと絵の具がたっぷり載り、速く払うと細くなって筆の毛の筋でかすれます。
             長く引くほど筆の絵の具が減ってかすれていき、線の終わりは払いのように細くなります。縁は乾いた水彩のように濃く、重ねると濃くなります
  クレヨン … 紙の目でぼそぼそ抜けて、縁がふわっとした線
  消しゴム … 選んでいるレイヤーだけ消す。「消し方」で 2 種類から選べます
             ピクセル     … なぞった所だけ消す
             オブジェクト … 触れた線を 1 本まるごと消す(なぞって何本かまとめて消すこともできます。戻す 1 回で全部戻ります)
             オブジェクトで消せるのは、最近描いた 100 本までです(それより古い線と、1.2 より前に描いて保存した絵は消せません)
  太さ / 不透明 … スライダーで変える

■ フチ(ペン・艶・マーカー・水彩)
  「フチ幅」を 0 より大きくすると、その道具の線にフチが付きます。0 に戻すとフチなし。
  フチ幅はペン・艶・マーカーごとに覚えます(ペンだけフチ付き、など)。水彩は選ぶたびにフチ幅 0 に戻ります(上げればフチが付きます)。
  続けて描いたフチ付きの線は、フチがまとまって 1 つの縁取りになります(文字を書いても先の線が切れない)。
  ネオン・消しゴムにはフチは付きません(選んでいる間はフチの欄が薄くなります)。
  ※ 1.0 までの「縁取り」は、ペンのフチ幅を上げたものと同じです。縁取りを選んでいた人は、ペン+そのフチ幅で開きます

■ 色
  「色」の四角を押すとパネルの中に色選びが開きます。#ff7fb3 のように色コードでも入れられます。
  フチの色は 自動 / 白 / 黒 / 自由 から選びます。自動はペンが明るい色なら黒、暗い色なら白のフチになります。
  「自由」を押すと、パネルの中でフチの色を選べます。
  丸い色見本は押すだけで切り替わります。
  色の四角の下のスポイトで色を拾えます。Chrome / Edge では画面のどこでも(ほかのウィンドウや配信プレビューの上も)拾えます。
  OBS の対話ウィンドウなどでは、スポイトを押してからボードを触ると、そこに描いてある色を拾います(Esc で取り消し)。
  「履歴」には実際に描いた色が新しい順に 8 個まで入ります。いらない色は右クリックで消せます。

■ 小パレット
  画面を右クリック(スマホ・タブレットは長押し)すると、その場に小さなパレットが出ます。
  色を押すとその色になって閉じます。上の段でペンも切り替えられます。パレットの外を触ると閉じます。
  指やペンでは、動かし始めてから線になります(長押しで点が残らないように)。タップすると点が描けます。

■ レイヤー
  1 / 2 / 3 … 押したレイヤーに描く。左の丸で表示 / 非表示
  このレイヤーを消す / 全部消す … 消したあとも「戻す」で戻せます(100 回まで)

■ 同じボードを 2 つ以上置くとき
  ローカルファイル版は、どのソースも同じ保存場所を使うので絵や履歴が混ざります。
  URL の最後に ?id=好きな名前 を付けると別々に保存されます(ブラウザ版の URL でも同じ)。

■ キーボード
  使えるのは Tab(UI を隠す / 出す)だけです。
  描いたものを戻すときは、パネルの「戻す」ボタンを押してください。
  (OBS の対話ウィンドウでキーボードの「元に戻す」を押すと、OBS 本体の操作が戻ってしまいます)
