# CHANGELOG

## 0.2.4 (2026-10-19)
- パークの設定: 一覧を DLC ごとに開く / 閉じるツリーにした(最初は全部閉じている。▶ か名前で開く。検索中はヒットした DLC を開いて見せる。「すべて開く / 閉じる」あり)
- パークの設定: 時期を「全期間 / 期間を指定」で選ぶようにした(期間を指定したときだけ DLC の範囲を出す)。今の条件(全期間なら何件の DLC か)を一覧の上に出す
- 一括ボタンを「この条件で全部入れる / 全部外す」に言い換え(閉じている DLC も含めて、時期と検索の条件に合うものが対象)

## 0.2.3 (2026-10-19)
- 背景の「透過」をブラウザでは市松模様で見せるようにした(tracker / デコポコと同じ。OBS では透明)。「自動」は透過と同じなのでなくし、透過 / ピンク / グリーンの 3 つにした

## 0.2.2 (2026-10-19)
- 背景をパネルで選べるようにした: 自動(OBS の中では透過、ブラウザではピンク)/ 透過 / ピンク / グリーン(クロマキー用)。URL の ?bg=transparent も今までどおり使える

## 0.2.1 (2026-10-19)
- 「パーク名」の表示 / 非表示を切り替えられるようにした(画像を出しているときだけ。消すとキャラ名も消える)

## 0.2.0 (2026-10-19)
- パークの設定: 時期(DLC)で絞り込めるようにした。一覧は DLC ごとにまとめ、DLC の行のチェックでまとめて切り替え
- パークの設定: 有効 / 無効のセットをプリセットとして保存・呼び出し(キラー / サバイバーそれぞれ 10 個まで)
- 「ひし形の枠」の表示 / 非表示を切り替えられるようにした(画像だけ・名前だけで置ける)
- ひし形の並びで、左右の名前が枠に重なっていたのを直した
- キラーの枠の赤を明るくした
