# パークスロット 使い方

Dead by Daylight のパーク 4 つをスロットで抽選するツールです。非公式のファンツールで、Behaviour Interactive とは関係ありません。

## 開き方
- Web 版: https://pokkomyu.github.io/poko-tools/tools/dbd-perks/ (パークの画像あり)
- zip 版: 解凍して index.html を開く(パークの画像はありません。名前だけで表示します)

## OBS に置く
1. ソースの「ブラウザ」を追加し、上の URL(zip 版は「ローカルファイル」で index.html)を指定。幅 1920 / 高さ 1080
2. 右側の操作パネルはクロップで隠す
3. 操作はソースを右クリック →「対話」で開いた窓で行う
4. 効果音を出すときは「OBS を介して音声を制御する」をオン

## 操作
- 「全部まわす」: 4 枠をまとめて抽選(固定した枠は変わらない)
- 枠をクリック / 「まわす」: その枠だけ抽選
- 「固定」: その枠を全部まわしたときも変えない
- 「コピー」: パーク名をコピー。ゲームの装備画面の検索に貼り付けて使う
- 「パークの設定」: 未所持・禁止のパークのチェックを外すと出なくなる(キラー / サバイバーで別)
- 横並び / ひし形、パークの画像、キャラ名、効果音はパネルで切り替え

設定は使っているブラウザ(OBS)に保存されます。同じページを OBS に 2 つ置くときは URL の最後に `?id=名前` を付けて分けてください。
