# CHANGELOG

## 0.1.0 (2026-11-05)
- poko-tools に収録した初版。受領した 1 ファイルの試作から次の点を変えた
- 画面を 1920x1080 の固定ステージ + 右の操作パネル 400px にして、ウィンドウに合わせて拡大縮小する。OBS のソースは 2320x1080、右 400px をクロップ
- フォント(M PLUS Rounded 1c、Orbitron を元にした CosmicDigits)を同梱した(Google Fonts は読み込まない)。オフラインでも同じ見た目
- URL パラメータ `id`(保存を分ける)と `bg=transparent` を追加
- 保存キーを `poko-cosmic-countdown-v1` に変更。古いキー `cosmicCountdown.v1` があれば読み込んで引き継ぐ
- 保存した内容を読み込むとき、壊れた値や足りない項目を補うようにした
- 毎年の項目が何年も前の日時でも、正しい年に繰り越す。2/29 は閏年でない年は 2/28
- カードを毎分作り直さず、変わった所だけ更新するようにした
- 星空アニメーションを OFF にしたとき、または画面が隠れているときは止める
- 表示の更新を 1 秒に 1 回にした
- 日時を変えたとき、進捗バーの開始点を「変えた時」にした
- 同じソースを 2 つ開いたとき、入力中の編集欄を作り直さない
- ▲▼の長押しがマウスを離しても止まらないことがあった不具合を直した
- 0 秒になった瞬間のお祝い演出を追加(動きを減らす設定では止まる)
- 対話ウィンドウで日本語が打てないことの注意書きを、入力欄の下に追加
- OBS の中では、項目が 0 件のときの案内文を出さない
