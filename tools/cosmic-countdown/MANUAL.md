コズミックカウントダウン 使い方
==============================

イベントや年越しまでの残り日数・時間を、星空デザインのカードで並べて表示します。
ビルドやインストールは不要です。index.html を開くだけで動きます。

■ ブラウザで使う
  index.html をダブルクリックして開くだけで使えます。
  (Chrome / Edge 推奨)
  ウィンドウの大きさに合わせて、画面全体が縮んだり広がったりします。

■ OBS で使う
  1. ソースの「+」→「ブラウザ」を追加
  2. 「ローカルファイル」にチェックを入れて index.html を選ぶ
  3. 幅 2320 / 高さ 1080 にする
  4. 映像に重ねたいときは、操作パネルの設定「背景を透過」を ON にする
     (既定は OFF で、星空の背景が映ります)
  5. ソースを右クリック →「変換」→「変換の編集」で、クロップの「右」を 400 にする
     (Alt キーを押しながら右端をドラッグしてもできます。
      クロップフィルタは対話画面の表示やクリック位置がずれることがあるので使いません)

  配信に映るのは左の 1920x1080 です。右端の 400px が操作パネルで、クロップで隠れます。
  操作はソースを右クリック →「対話」で開くウィンドウから行います。
  対話ウィンドウにはクロップした部分も表示されます。

■ ソースの大きさを変えたいとき
  ブラウザソースの幅・高さは 2320x1080 のままにして、シーン上でソースを縮めてください。
  幅を変えるとクロップの位置がずれて、操作パネルの端が映ったり、カードが切れたりします。

■ できること
  - カウントダウンの追加、編集、削除、並び替え
  - 日時を▲▼ボタンか数字の入力で設定(長押しで連続して変わる)
  - 絵文字アイコンの選択、当日に表示する文字の設定
  - 「毎年くりかえす」設定(年越し、誕生日など)
  - 見出しとサブテキストの変更
  - 縦/横の並び替え、表示サイズの変更(40〜300%)
  - 表示の切り替え: 近い順の自動並び、終わったイベントを隠す、背景の透過、
    星空アニメーション、見出しの星マーク、進捗バー

■ 動作の決まりごと
  - 当日の表示: 設定した日時から 24 時間はお祝いの文字を表示します。
    その後、普通の項目は「終了しました」になり、毎年の項目は翌年のカウントに切り替わります。
  - 毎年の項目で 2/29 を設定した場合、閏年でない年は 2/28 として数えます。
  - 進捗バー: 開始から設定日時までのうち、今どこまで過ぎたかを表します。
    開始点は、普通の項目なら「追加した時、または日時を変えた時」、
    毎年の項目なら前回の同じ日時です。
  - 保存: 変更はその場でブラウザの localStorage に自動保存します。
  - データの引き継ぎ: イベントの内容はファイルに含まれません。
    別の環境で開くと、サンプルの 2 件(年越し、記念配信)から始まります。
    OBS のキャッシュを消したり、ファイルを別の場所に移したりすると、データが消える場合があります。
  - 0 秒になった瞬間、そのカードにお祝いの演出が出ます。
    OS の設定で「視差効果を減らす」を選んでいると、動く演出は止まります。

■ 日本語の入力(対話ウィンドウ)
  OBS の「対話」ウィンドウでは日本語入力(IME)が使えません。
  OBS 側の制限で、ツールでは直せません。
  メモ帳などで書いてコピーし、入力欄に Ctrl + V で貼り付けてください。
  (ブラウザと OBS は保存が別なので、項目は OBS の対話ウィンドウで入れてください)

■ URL パラメータ(上級者向け)
  OBS のブラウザソースで、「ローカルファイル」のチェックを外し、URL 欄に
  次のように入れます。
    file:///C:/.../cosmic-countdown/index.html?id=main
  (パラメータが要らないときは、従来どおり「ローカルファイル」で使えます)

  id=<名前>   保存を分けます。半角英数字・- ・_ で 1〜32 文字。
              同じ id のソース同士だけが同じ内容を共有します。
              例: 配信用と別のカウントダウンを同じ PC で使いたいとき。
              条件に合わない値は無視して、id なしの保存を使います。
              id を付けた場合は、新しい保存として始まります(id なしの内容は引き継ぎません)。
  bg=transparent
              OBS の外で開いたときも、市松模様を出さず透明のままにします。
              (設定の「背景を透過」が ON のとき)

■ フォント
  文字は同梱のフォントで表示します(インターネットに接続していなくても同じ見た目です)。
  index.html だけを別の場所に移さず、fonts フォルダごと使ってください。
