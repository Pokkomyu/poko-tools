# CREDITS

同梱素材は次のフォントだけです。どちらも SIL Open Font License 1.1(OFL)で、再配布できます。ライセンス全文は `fonts/` に同梱しています。

- M PLUS Rounded 1c(Medium / ExtraBold): 著作者 The Rounded M+ Project Authors(Coji Morishita, M+ Fonts Project)。入手元: https://github.com/google/fonts/tree/main/ofl/mplusrounded1c 。ライセンス: `fonts/OFL-MPLUS.txt`(全文は https://github.com/coz-m/MPLUS_FONTS の OFL.txt、先頭の著作権表記はフォント内の表記に合わせた)。必要な文字だけに subset して woff2 に変換した(`fonts/MPLUSRounded1c-*.subset.woff2`)。M PLUS Rounded 1c の OFL は予約フォント名を指定していないので、subset 後も名前は変えていない
- Orbitron(SemiBold / ExtraBold): 著作者 The Orbitron Project Authors(https://github.com/theleagueof/orbitron)。入手元: https://github.com/google/fonts/tree/main/ofl/orbitron 。ライセンス: `fonts/OFL-Orbitron.txt`。可変フォントから太さ 600 と 800 を切り出し、半角英数字記号だけに subset して woff2 に変換した(`fonts/CosmicDigits-*.subset.woff2`)。Orbitron は OFL の予約フォント名(Reserved Font Name)なので、改変版(subset)のフォント内の名前とファイル名は「CosmicDigits」に変えた。著作権表記はそのまま残している
- 読み込めなかった時の代わり: ヒラギノ丸ゴ / BIZ UDPGothic / 游ゴシック UI / メイリオなど OS 標準のフォント(同梱なし)
