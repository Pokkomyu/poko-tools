# CHANGELOG

## 0.4.2 カラー版 (2026-10-06)
- 長い名前を「…」で切らずに、文字を小さくして収めるようにした(ルーレット盤・当選表示)。小さくしても入りきらない時だけ「…」で省略する
- 無料版 0.3.4 の変更を取り込んだ

## 0.4.1 カラー版 (2026-10-04)
- スマホ表示に対応。画面の幅が狭い(900px 未満)か縦長の時は、ルーレットと当選履歴を横一列のまま幅に合わせて縮小し、その下に START と操作パネルを並べる(OBS 内では従来どおり 1920x1080)
- 無料版 0.3.2・0.3.3 の変更(「当選履歴」の表記、スマホ表示)を取り込んだ

## 0.4.0 カラー版 (2026-10-02)
- 操作パネルを「名前」「配色」のタブに分けた
- 配色のプリセット 9 種(宇宙猫 / ぽこ / パステル / ビビッド / さくら / うみ / ゆめかわ / モノトーン / ハロウィン)。盤・針・当選表示・一覧・回数表示・背景の色がまとめて変わる。初期状態は「宇宙猫」
- パーツごと(27 か所)に色を変えられる。代表色から選ぶ / カラーパレットで選ぶ / RGB・HEX で入力、の 3 通り
- プリセットの色を変えると「新規配色1」のように別名で自動保存される(5 つまで)。名前の変更と削除ができ、選んだ配色は次に開いた時も残る
- 名前の「シャッフル」ボタン(順番をランダムに入れ替える。入れ替わる演出付き)と、オプション「毎回シャッフル」(START のたびにシャッフルしてから回す)を追加
- 無料版 0.3.1 の変更(OBS の対話では日本語が打てない旨の案内)を取り込んだ
- カラー版は有償版です。無料版(0.3.x)の機能はすべて含みます

## 0.3.1 (2026-09-28)
- 入力欄の下に「OBSの対話では日本語が打てないので、メモ帳などで書いて貼り付けてね」の案内を追加(OBS 側の制限)

## 0.3.0 (2026-09-27)

## 0.2.0 (2026-09-24)

- 名前が0人の時の「名前を追加してね」を中心の飾りと重ならない位置に移動
- オプション「当選時の「おめでとう!」」「当選時のファンファーレ」を追加(当たり/はずれルーレット用にオフにできる)
- 1人だけの時の名前の位置を、空の時の案内文と揃えた
