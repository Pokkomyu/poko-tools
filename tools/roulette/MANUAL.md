ぽこルーレット カラー版 使い方
==============================

■ ブラウザで使う
  index.html をダブルクリックして開くだけで使えます。
  (Chrome / Edge 推奨)

■ OBS で使う
  1. ソースの「+」→「ブラウザ」を追加
  2. 「ローカルファイル」にチェックを入れて index.html を選ぶ
  3. 幅 1920 / 高さ 1080 にする
  4. 効果音を配信に乗せたい場合は「OBSを介して音声を制御する」にチェック
  5. 背景は自動で透明になります

■ 操作パネルを配信に映さない
  ソースを選んで Alt キーを押しながら右端をドラッグしてクロップします。
    - 右側の「操作パネル」だけ隠す   → 右から約 890px をクロップ
    - 「当たった人の一覧」も隠す    → 右から約 1230px をクロップ
  (右クリック →「変換」→「変換の編集」でクロップの数値を直接入れることもできます)

  操作はソースを右クリック →「対話」で開くウィンドウから行います。
  対話ウィンドウにはクロップした部分も表示されます。

■ 名前を入れる
  入力欄に名前を書いて「追加」。
  改行で区切ってまとめて貼り付けると、一度に何人でも追加できます。
  (Ctrl + Enter でも追加できます)

■ オプション
  当たったら消す             当選した人をルーレットから外します
  連続で同じ人に当たらない   直前に当たった人は次の回で当たりません
  何回回したかを表示         ルーレットの左上に「〇回目」を出します
  効果音                     回転音と当選音のオン/オフ
  当選時のファンファーレ
                             オフにすると当選音だけ鳴らしません
                             (「当たり/はずれ」を回す時などに)
  当選時の「おめでとう!」
                             オフにすると名前だけを表示します
                             (「当たり/はずれ」を回す時などに)

■ 配色(カラー版の機能)
  操作パネルの「配色」から好きな配色を選びます。
  ルーレットの色、見出し・ボタン・針の色がまとめて変わります。
  選んだ配色は保存され、次に開いた時もそのままです。
    ぽこ / パステル / ビビッド / さくら / うみ / ゆめかわ / モノトーン / ハロウィン

■ 結果クリア
  当たった人の一覧と回数をリセットします。
  「当たったら消す」で外れた人もルーレットに戻ります。

■ 全消去
  名前をすべて消します。誤操作防止のため2回押しです。

■ 保存について
  名前・オプション・結果は自動で保存され、次に開いた時も残っています。
  ブラウザと OBS では別々に保存されます。
