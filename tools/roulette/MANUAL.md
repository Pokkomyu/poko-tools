ぽこルーレット カラー版 使い方
==============================

■ ブラウザで使う
  index.html をダブルクリックして開くだけで使えます。
  (Chrome / Edge 推奨)

■ スマホで使う
  スマホ(画面の幅が狭い時や縦長の時)で開くと、スマホ向けの並びになります。
  上にルーレットと当選履歴が横一列で並び、その下に START と操作パネルが出ます。
  操作パネルは下にスクロールすると見られます。

■ OBS で使う
  1. ソースの「+」→「ブラウザ」を追加
  2. 「ローカルファイル」にチェックを入れて index.html を選ぶ
  3. 幅 1920 / 高さ 1080 にする
  4. 効果音を配信に乗せたい場合は「OBSを介して音声を制御する」にチェック
  5. 背景は自動で透明になります

■ 操作パネルを配信に映さない
  ソースを選んで Alt キーを押しながら右端をドラッグしてクロップします。
    - 右側の「操作パネル」だけ隠す   → 右から約 890px をクロップ
    - 「当選履歴」も隠す    → 右から約 1230px をクロップ
  (右クリック →「変換」→「変換の編集」でクロップの数値を直接入れることもできます)

  操作はソースを右クリック →「対話」で開くウィンドウから行います。
  対話ウィンドウにはクロップした部分も表示されます。

■ 名前を入れる
  入力欄に名前を書いて「追加」。
  改行で区切ってまとめて貼り付けると、一度に何人でも追加できます。
  (Ctrl + Enter でも追加できます)
  長い名前は、ルーレットと当選表示の中で文字を小さくして収めます。
  小さくしても入りきらない時だけ、最後を「…」で省略します。

  ※ OBS の「対話」ウィンドウでは日本語入力(IME)が使えません。
     OBS 側の制限で、ツールでは直せません。
     メモ帳などで名前を書いてコピーし、入力欄に Ctrl + V で貼り付けてください。
     (ブラウザと OBS は保存が別なので、名前は OBS の対話ウィンドウで入れてください)

■ シャッフル
  「シャッフル」ボタンで名前の順番をランダムに入れ替えます(盤の並びも変わります)。

■ 止まり方
  減速のしかた・最後にじわじわ進む長さは毎回変わります。
  針が境目で粘って、ギリギリ越えたり押し返されたりすることもあります。
  当たる人は START を押した時点で公平に決まっていて、演出で変わることはありません。

■ オプション
  当たったら消す             当選した人をルーレットから外します
  連続で同じ人に当たらない   直前に当たった人は次の回で当たりません
  毎回シャッフル             START を押すたびに、シャッフルしてから回します
  何回回したかを表示         ルーレットの左上に「〇回目」を出します
  効果音                     回転音と当選音のオン/オフ
  当選時のファンファーレ
                             オフにすると当選音だけ鳴らしません
                             (「当たり/はずれ」を回す時などに)
  当選時の「おめでとう!」
                             オフにすると名前だけを表示します
                             (「当たり/はずれ」を回す時などに)

■ 配色(カラー版の機能)
  操作パネル上部の「配色」タブで切り替えます。
  (名前の追加やオプションは「名前」タブ。START はどちらのタブでも押せます)

  ・プリセット
      宇宙猫 / ぽこ / パステル / ビビッド / さくら / うみ / ゆめかわ / モノトーン / ハロウィン
      (最初は「宇宙猫」になっています)
      ルーレット盤・針・当選表示・当選履歴・回数表示・背景の色が
      まとめて変わります。

  ・パーツごとに色を変える
      左の一覧からパーツ(盤の色 1〜6、名前の文字、針、当選表示の枠…)を選び、
      右で色を決めます。決め方は 3 通りです。
        代表色      … 並んだ色をクリック
        パレット    … 上の四角で明るさと鮮やかさ、下の帯で色相をドラッグ
        R / G / B   … 0〜255 の数字、または HEX(#ff8fc7 など)を入力
      プリセットの色を変えると「新規配色1」のような名前で自動で保存され、
      「保存した配色」に並びます(5 つまで)。名前は右上の欄で変えられ、
      × で削除できます。プリセット自体は変わりません。

  ・選んだ配色と保存した配色は、次に開いた時もそのままです。
    (ブラウザと OBS では別々に保存されます)

■ 結果クリア
  当選履歴と回数をリセットします。
  「当たったら消す」で外れた人もルーレットに戻ります。

■ 全消去
  名前をすべて消します。誤操作防止のため2回押しです。

■ 保存について
  名前・オプション・結果は自動で保存され、次に開いた時も残っています。
  ブラウザと OBS では別々に保存されます。
