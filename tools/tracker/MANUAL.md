本日のチャレンジ 使い方
======================

配信画面に出せる、やることリスト付きの作業トラッカーです。

■ 色を選ぶ
  pink.html / red.html / white.html / black.html / purple.html / quest.html(クエスト画面風)
  文字はすべてフォント「けいふぉんと!」です。assets フォルダのフォントを使うので、
  HTML だけを別の場所に移さず、フォルダごと使ってください。
  色違いは配色だけ変えています。操作は同じです。
  記録は色ごとに別々です(ファイルを変えるとタスクは共有されません)。

■ OBS で使う
  1. ソースの「+」→「ブラウザ」を追加
  2. 「ローカルファイル」にチェックを入れて使いたい色の .html を選ぶ
     (ブラウザ版を使う場合はチェックを外して URL を貼る)
  3. 幅 720 / 高さ 900 くらいにする
     (ブラウザで開くと背景が市松模様に見えますが、OBS では透明になります)
  4. シーンを切り替えるたびに時間が戻る場合は
     「シーンがアクティブになったときにブラウザを更新」をオフにする

■ 操作欄を配信に映さない
  プレビュー上でソースを選び、Alt キーを押しながら右端をドラッグして、右の操作欄をクロップします。
  操作はソースを右クリック →「対話」で開くウィンドウから行います。
  対話ウィンドウを横に広げると、右に ＋ と「まとめて追加」欄が出ます。

■ 操作
  開始 / 一時停止 … 経過時間を測る
  時間リセット     … 経過時間だけゼロに戻す(タスクは残る)
  ＋               … 行を1つ追加する
  チェック         … 完了。そのときの経過時間が右に出る
  タスク名         … 対話で直接書き換えできる
  ×               … その行を削除する

■ 日本語でまとめて追加
  OBS の「対話」ウィンドウでは日本語入力(IME)が不安定です。
  1. メモ帳でタスクを書く(1行が1件)
  2. 対話の「まとめて追加」欄に貼る
  3. 「貼り付けて追加」を押す
