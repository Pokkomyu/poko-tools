# 利用規約の方針

無料版ツールの利用規約(`packaging/LICENSE_ja.md`、zip には `利用規約.txt` として入る)の考え方(2026-10-04 ぽこ決定)。

| | 無料版 | 有償版(plus) |
|---|---|---|
| 配信・動画での使用(収益化を含む) | 可 | 可 |
| 改変(プログラムを含む) | 可 | 個人での見た目・文言の改変のみ |
| 改変したものの無償配布 | 可(元が星乃ぽこ作であることと、改変したことを明記) | 不可 |
| 改変せずにそのまま再配布 | 不可 | 不可 |
| 販売・転売・有償配布 | 不可 | 不可 |
| 自作発言 | 不可 | 不可 |

- 「そのまま自分のものとして再配布」は禁止、「コードを改変する」は認める、という姿勢。改変版を配る時は、元が星乃ぽこ作だと分かるようにしてもらう
- 有償版はメンバー限定の中身が出回らないよう、改変版の配布も禁止のまま(`edition/plus` の `packaging/LICENSE_plus_ja.md`)
- リポジトリ直下の `LICENSE.md` は GitHub で見る人向けの要約。正本は `packaging/LICENSE_ja.md`
- 公式サイトの文面(wp-poko の `bin/content/tools/terms.html` と各ツールの案内ページ)も同じ内容にそろえる
- `tracker` の元 repo(`Pokkomyu/obs-work-tracker`)は MIT で公開していた。それまでの版は MIT のまま(取り消せない)。poko-tools に移した版からこの規約に従う
