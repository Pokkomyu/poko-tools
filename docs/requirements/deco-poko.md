# デコポコ(お絵かきボード) 仕様

名前は decoration と「デコボコ」をかけたもの(2026-10-15 ぽこ決定)。最初は自分用の最小構成で作る。

## 画面
- 全画面のキャンバス(ウィンドウの大きさ = 描ける範囲)。OBS のソースは 1920x1080 を推奨
- conventions.md の「1920x1080 固定ステージ」の例外。座標はウィンドウの px そのままで、拡大縮小はしない(描いた位置がずれないように)
- 操作パネルは右下のボタンで開閉する浮動パネル。ドラッグで移動できる。**クロップではなく Tab で隠す**(描く場所とパネルが同じ面にあるため)
- 背景は OBS 内(`window.obsstudio` あり)では透過。OBS の外では市松模様(`?bg=transparent` で透過のまま)。roulette / tracker と同じ

## 機能
- 描くのは最初に触れた指(ポインター)だけ。描いている間の 2 本目以降の指は無視する。2 本指での拡大縮小はできない(2026-10-16 ぽこ報告: 2 本指で触ると指の間が線でつながった。0.2.2)
- 道具: ペン / 縁取り(フチ付き) / 消しゴム(選択中レイヤーのみ) / ネオン / マーカー
  - ネオン・マーカー・フチ色の自由選択・小パレットはプラス版 0.5.x で作り、1.0.0 で無料版に入れた(2026-10-16 ぽこ「デコポコ plus(コラボ機能なし)を普通にデコポコで出す」)
  - ネオンペン: 線の色で周りが光り(shadowBlur = 太さ × 1.5 + 6)、中心に白っぽい芯(色と白を 3:7)。ネオンが続く間は縁取りと同じ「まとまり」にして、光(色・太さ・濃さが同じ線は 1 つの形にしてから 1 回だけ光らせる)→ 線 → 芯 の順に描く(1.0.1。線ごとに重ねると、あとの線の光が先の線の芯にかぶって画数の多い字が読めなかった)
  - マーカーペン: 平たい(チゼル型)ペン先を 75° に固定し、区間ごとの四角形で塗る(ぽこの見本)。濃さはマーカーを選んでいる間の「不透明」スライダー(初期 40%、ペンの不透明度とは別に保存)。濃さが同じマーカーが続く間は重ねても濃くならない。縁取りの「まとまり」と同じ仕組みで、ペン・ネオン・消しゴム・消去・濃さの変更で区切る
  - 画面に出る小パレット: 右クリック(マウス)/ 長押し 0.5 秒(指・ペン)で、その場に色(プリセット + 履歴、16 色まで)とペンの切り替え。外を触ると閉じ、その操作では描かない。配信画面にも一瞬映る(パネルと同じ扱い)
  - 指・ペンは 8px 動くまで線を始めない(長押しで点が残らないように)。動かさずに離すと点
- 重なり順: 同じレイヤーではあとから描いた線が上、レイヤーは 3 が一番上。縁取りは **続けて描いている間はフチをまとめる**(まとまり全体で「フチを全部 → 線を全部」の順に描く)。普通のペン・消しゴム・消去を挟むとまとまりを区切り、その後の縁取りは前の絵の上に「フチ+線」で重なる(2026-10-16 ぶらんち。0.2.1)
  - 経緯: 0.1.0 はフチをレイヤー全体の下に敷いていて、あとから描いた縁取りのフチが先に描いたペンの下に回った(ぽこ報告)。0.1.1 で線 1 本ごとに「フチ+線」にしたら、文字を書くと後の線のフチが先の線を切って見づらくなった(2026-10-16 ぶらんち)。0.2.1 で両方を満たす形にした
  - 実装: レイヤーごとに「続いている縁取りの op」と「その縁取りが始まる前の画像」を持つ。戻せない部分(base)にもまとまりを持たせ、base をまたいで続く縁取りもつながる
- フチ色は 自動 / 白 / 黒 / 自由(自由は 1.0.0 から。2026-10-15 ぽこ「一旦白と黒で選べるように」)。自動(既定)は ペン色の相対輝度 > 0.5 なら黒、それ以外は白。白ペン+白フチで太い白線になるだけ、という報告への対応。フチ幅 1〜30
- 太さ 1〜80、不透明度 5〜100%
- レイヤー 3 枚(表示切替あり)。戻す / やり直す 100 回、このレイヤーを消す / 全部消す
- 戻す / やり直すは操作ログ方式(0.2.0〜)。線と消去を op として記録し、戻すときはそのレイヤーを「base + op」で描き直す。100 回を超えた古い op は base に焼き込む。保存(localStorage)はレイヤーの画像だけで、再読み込みした絵は base になる(読み込み前には戻せない)。一緒にデコる(`docs/architecture/deco-poko-collab.md` §4)の土台
- 保存は localStorage(`poko-deco-poko-v1`)。設定と絵をまとめて保存する
- `?id=<名前>` で保存キーを `poko-deco-poko-v1:<名前>` に分ける。OBS のローカルファイル指定はすべて同じ origin になり、同じボードを複数置くと絵と履歴が混ざるため

## 色
- ペン色の選択はパネル内蔵のピッカー(SV 四角 + 色相バー + 色コード入力)
  - ブラウザ標準の `<input type=color>` は使わない。OBS の対話ウィンドウではポップアップが正しく出ない / 位置がずれることがあり、意図しない色が選ばれる(「履歴に知らない色が入る」報告の推定原因、2026-10-15)
- プリセット 8 色(白・黒・ピンク・赤・黄・緑・青・紫)
- 履歴: **実際に描いた色だけ** を新しい順に 8 個。プリセットの色は入れない。RGB 距離 24 未満の近い色は同じ色として新しい方に置き換える。右クリックで 1 個削除
  - 消しゴムでは履歴に入れない

## キー操作
- Tab: UI を隠す / 出す。**それ以外のキーは割り当てない**(2026-10-15 ぽこ決定)
  - 1 文字キー(B / E / Z など)は OBS の対話中に誤爆しやすく、何が起きたか分かりにくい
  - Ctrl+Z は OBS の対話では OBS 本体の「元に戻す」に吸われる。連打したらブラウザソースを追加する前までシーンが戻った(2026-10-15 ぽこ確認。受け取った最初の HTML で、画面に Ctrl+Z の表記があった)。画面・説明に Ctrl+Z の表記は出さない
  - GitHub Pages 版 / hoshino-poko.com から案内した場合の挙動は未検証。Pages 版も OBS の対話で使うなら同じはずだが、公開後に確かめる

## 配布(2026-10-16 ぽこ決定)
- 無料版 = 一緒にデコる以外の全機能。GitHub Pages、BOOTH 無料、BOOTH 開発支援版(中身は無料版と同じ)
- 一緒にデコるは、ぽこにゃー(サーバー)が中継するので zip では動かない。サーバー負荷の心配から無料公開は保留し、当面はプラス版の Web 版(hoshino-poko.com/tools/plus/deco-poko/)だけに置く。BOOTH で有償版は出さない
- 無料版で一緒にデコるを出す方法(WebRTC でホストのブラウザ中心、TURN なし)は `docs/architecture/deco-poko-collab.md` §12(ドラフト)で検討中

## プラス版(デコポコ プラス)の機能
無料版の全機能に、一緒にデコるを足したもの(`edition/plus`)。ペン類は 1.0.0 で無料版に移したので、プラス版だけのコードは `collab.js` と、その読み込み・保存キーの分け方だけにする(`index.html` には `window.decoBoard` の呼び出し口を無料版にも残す。無料版の一緒にデコるを作るときにも使う):

- 一緒に描く / 一緒にデコる(コラボ。「プリクラ機能」より「一緒にデコる」の方が伝わる、とぽこ)
  - Web 版(hoshino-poko.com のプラス版配信)だけの機能にする。単体版(zip / ローカルファイル)では考えない(2026-10-15 ぶらんち)。conventions.md の「file:// で 1 ページ完結」の例外はこの機能だけ
  - 同期は pokonya の WebSocket(送るのは線の座標・色・太さだけで軽い)
  - 自分の線だけ戻すための操作ログ方式は 0.2.0 で無料版に入れた(段階 0)
  - 設計: `docs/architecture/deco-poko-collab.md`
- 一緒にデコるは 0.3.0 で 2 人、0.4.0 でホスト + ゲスト 3 人(人ごとの席、設計 §11)
