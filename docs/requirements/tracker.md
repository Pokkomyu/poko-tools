# 本日のチャレンジ(作業トラッカー) 仕様

出典: `Pokkomyu/obs-work-tracker`(星乃ぽこ自作、2026-10-04 に poko-tools へ移植)

## 画面(720x900 目安、背景透過)

| 領域 | 位置(目安) | 配信に映す |
|---|---|---|
| トラッカー本体(タイトル・経過時間・タスク一覧) | 左 幅 430px | 映す |
| 対話用メニュー(＋・開始/一時停止・時間リセット・まとめて追加) | 右 幅 240px | 映さない(クロップ) |

- conventions.md の「1920x1080 固定ステージ」の例外。元の作りのまま、拡大縮小はしない(OBS 側でソースの大きさを変える)
- 背景は OBS 内(`window.obsstudio` あり)では透過。OBS の外ではプレビュー用に市松模様を出す(2026-10-04。`?bg=transparent` で透過のまま。roulette と同じ切り替え)

## 色(テーマ)

| ファイル | 見た目 |
|---|---|
| `pink.html` | ピンク |
| `red.html` | 赤 |
| `white.html` | 白 |
| `black.html` | 黒 |
| `purple.html` | 紫 |
| `quest.html` | クエスト画面風(非公式デザイン。特定ゲームの名前・素材・ロゴ・フォントは使わない) |
| `pink-keifont.html` | ピンク / けいふぉんと(`assets/keifont/keifont.ttf` を同梱、約 4.3MB) |

- 1色 = 1ファイル。保存キーも色ごと(`poko-tracker-<色>-v1`)で、記録は共有しない
- `index.html` は色を選ぶページ(OBS に貼る URL を表示する)
- けいふぉんと版はフォントを同梱して公開する(2026-10-04 決定。Apache License 2.0 で再配布可。file:// でも同じフォルダのフォントを読める)。漢字入りでサブセット化はしない(タスク名に任意の文字が入るため)

## 機能
- 経過時間: 開始 / 一時停止 / 時間リセット(タスクは残る)
- タスク: ＋で追加、チェックで完了(完了時の経過時間を表示)、名前は対話で直接編集、×で削除
- まとめて追加: 改行区切りで貼り付け(OBS の対話は IME が不安定なため)
