# 名前ルーレット 仕様

出典: `docs/ux/roulette/wireframe-v1.png`(星乃ぽこ 2026-09-18)

## 画面(1920x1080、背景透過)

| 領域 | 位置(目安) | 配信に映す |
|---|---|---|
| ルーレット盤 + ひし形の星(真上の針) | 左 x=0〜690 | 映す |
| 当選履歴 | 中央 x=690〜1000 | 選べる(クロップ位置で調整) |
| 操作パネル(OBSの対話部分) | 右 x=1040〜 | 映さない(クロップ) |

## スマホ表示(0.3.3〜、2026-10-04 要望)
- 幅 900px 未満か縦長(幅 < 高さ)の時に切り替える。OBS 内(`window.obsstudio`)では切り替えない
- ルーレット盤と当選履歴は **横一列のまま**(990x740 の領域)、画面幅に合わせて縮小する。横向きでも START まで 1 画面に入るよう高さでも制限する
- 操作パネルはその下に等倍で縦に並べ、START / 結果クリアを一番上(ルーレットのすぐ下)に出す。ページは縦スクロール

## 盤面
- 項目ごとに色分け。ピンク・白・青・赤・紫・黄色の順で繰り返す
- 隣り合う項目が同じ色にならないようにする
- 針は黄色のひし形の星、盤の真上
- 名前の大きさ(2026-10-06 ぽこ要望「名前長いのはサイズ小さくなっておさまるようにした方がよさそう」、0.3.4)
  - 基準の大きさは項目数で決める(半径 300 の盤で最大 40px、1人だけの時は 48px)
  - 入りきらない名前だけ個別に縮める。下限は **基準の 0.5 倍(項目が少ない時は 20px)、ただし 14px 未満にはしない**。下限でも入らない時だけ末尾を「…」で省略する
  - 入りきるかは、名前を置く幅(外側 0.9r から中心の飾りの手前 0.16r まで。1人だけの時は横書きで 1.5r)と、名前の内側の端での扇形の幅(弦)が文字の高さ以上あることの両方で判定する(項目が多い時に隣の名前と重ならないように)

## 操作パネル
- 名前一覧(番号付き)。個別に削除できる
- 入力欄に **改行区切りでコピペ → 追加** で複数追加
- 入力欄の下に「OBSの対話では日本語が打てないのでメモ帳などで書いて貼り付け」の案内を常時表示(2026-09-28 ぽこ要望)。OBS の対話ウィンドウは IME 非対応(obs-browser の既知の制限、obsproject/obs-browser#69・#227)でページ側では直せないため。貼り付け(Ctrl+V)は OBS 27 以降で可
- START: 押したら勝手に止まる。当たりは完全ランダム
- 結果クリア
- オプション(チェックボックス)
  - 当たったら消す
  - 連続で同じ人に当たらない
  - 何回回したかを表示する
  - 当選時の「おめでとう!」(既定オン。2026-09-23 ぽこ要望: 当たり/はずれを回す時にはずれで祝わない)
  - 当選時のファンファーレ(既定オン。同上。「効果音」がオフなら鳴らない)

## 演出
- 止まったら当たった人の名前を盤の真ん中に大きく表示(5秒)。「おめでとう!」の見出しはオプションで消せる
  - 名前は 110px から枠に収まるまで縮める。1行で 56px まで縮めても入らなければ2行に折り返し、さらに **24px** まで縮める(全角 40 文字=入力の上限が2行に入る大きさ)。24px でも入らない時だけ「…」で省略する
  - 当選履歴と操作パネルの名前一覧は従来どおり1行で「…」省略
- 回転中、項目の境目が針を通るたびに針が弾かれてプルプル揺れ、すぐ収まる。止まる瞬間は揺れない(2026-09-23 ぽこ要望)
- 針の粘り(2026-10-08 ぽこ要望「矢印が粘って押し返すこともある、みたいな演出」、0.3.5)
  - ゆっくりの時、次の境目が針に触れる範囲(7°、項目の幅の 15% まで)に入ると針が押されて傾く(最大 14°)。境目を越えるとその傾きから弾け戻る。止まる位置は触れる範囲の外
  - 止まる直前に毎回抽選(重み): 粘りなし 50 / 当たりに入る境目で粘ってギリギリ越える 30 / 一度押し返されてもう一回押して越える 5 / 当たりを通り過ぎかけて次の境目で押し返される 10 / 押し返し 2 回 5
  - 押し返しが起きる回は合わせて 2 割(通り過ぎかけて押し返されるのは 1.5 割)。0.3.5 は 4 割で多すぎた(2026-10-09 ぽこ要望「押し返しは1〜2割」、0.3.6)
  - 押し返し系は項目が 5 未満(1 項目が大きい)の時は出さない。1 項目だけの時は粘りなし
  - 当たりは START 時に決め、演出は止まる位置の前後の動きだけを変える(当たりが変わることはない)
- 名前が0人の時の案内文は中心の飾りと重ならないよう上に表示(2026-09-23 ぽこ要望)
- 当たった人は「当選履歴」に追加

## 実装で決めたこと(ぽこ確認待ち)
| 項目 | 仮の決定 | 理由 |
|---|---|---|
| 結果クリアの範囲 | 一覧と回数をリセットし、「当たったら消す」で消えた人も盤に戻す | 企画をやり直す時に1ボタンで戻せる |
| 効果音 | 回転中のカチカチ音と当選音を付ける(Web Audio合成、オン/オフ可) | 素材ライセンス不要。Discordで要望あり |
| 回転時間 | 約5.5〜14秒(中央 9 秒)でランダム。減速 3.8〜5.8秒 → じわじわ → 針の粘り(ある回のみ 1.5〜4秒) | 毎回同じだと単調。じわじわは 2026-09-27 ぽこ要望「止まる直前はゆっくり、どれだーーってなる瞬間」 |
| 減速の形 | 速度を (1-s)^p で落とし、p を毎回 1.2〜2.5 で選ぶ(0.3.4 までは p=3 固定) | 2026-10-08 ぽこ要望「減速急すぎ」。p が小さいほど緩やかに長く伸びる |
| じわじわの長さ | 毎回3種から抽選(重み 3:4:3)。あっさり: 境目の 8〜14° 手前から 1.4〜2.2秒 / ふつう: 14〜24° 手前から 2.2〜3.2秒 / 長い: 25〜70° 手前(名前をいくつか通り過ぎる)から 3〜4.2秒。粘りがある回は時間を 0.7 倍。開始の速さは 45°/秒まで(超える時は時間を延ばす) | 2026-10-08 ぽこ要望「じわじわ進むモードの長さがワンパターン」 |
| 当選履歴 | 新しい人が下。あふれたら最新が見えるようにスクロール | |
| 回数表示の位置 | 盤の左上 | |
| 保存 | 名前・オプション・一覧・回数はブラウザに自動保存 | 配信ごとに入れ直さなくてよい |
