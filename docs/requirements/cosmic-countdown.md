# カウントダウン(星空カード) 仕様

出典: 配信者から受領した 1 ファイルの試作(`cosmic-countdown.html` と README、2026-11-05 に poko-tools へ収録)

## 概要
- イベントや年越しまでの残り日数・時間を、星空デザインのカードで並べて表示する OBS 用ツール
- 項目は何件でも追加でき、毎年くりかえす設定もある

## 画面
| 領域 | 位置 | 配信に映す |
|---|---|---|
| ステージ(星空・見出し・カード) | 左 1920x1080 | 映す |
| 操作パネル | 右 幅 400px | 映さない(クロップ) |

- ページ全体は 2320x1080。OBS のソースは幅 2320・高さ 1080 で、右 400px をクロップする
- ウィンドウに合わせて、ページ全体を比率を保って拡大縮小する(conventions.md の固定ステージ)
- 背景は OBS 内(`window.obsstudio` あり)では透過。OBS の外では市松模様(`?bg=transparent` で透過のまま)

## 直すときに守ってほしいこと
出典: 配信者の要望

| 内容 | 理由 | 出典 |
|---|---|---|
| 操作はすべて右端のパネルに置き、ポップアップにしない | OBS のクロップで隠す前提のため | 配信者の要望 |
| パネルの幅は 400px のまま(変えるなら `--panel` とクロップの案内も一緒に) | クロップの幅と合わせるため | 配信者の要望 |
| ドロップダウン(`select`)を使わず、ボタンにする | OBS の対話で操作できないと報告があったため | 配信者の要望 |
| ON/OFF はチェックボックス形式の見た目にする | ON/OFF 表記だと状態が分かりにくかったため | 配信者の要望 |
| 時間は「あと◯日」の下に固定し、どちらもカードの左右中央に置く | 桁数で位置が変わると見づらいため | 配信者の要望 |
| パネルのボタン背景と項目名の文字はピンクにする | 配信者の好み | 配信者の要望 |
| 初期状態は横並びにする | 配信者の好み | 配信者の要望 |
| 猫のキャラクターは表示しない(絵文字の 🐱 は OK) | 星をモチーフにする方針のため | 配信者の要望 |
| 絵文字候補に 🪐 🌟 💫 ☄️ を入れない | 配信者の好み | 配信者の要望 |
| 日付・時刻のショートカットやバックアップ用のコピーボタンを付けない | 不要と判断されて削除したため | 配信者の要望 |

- カレンダー入力(`datetime-local`)と、`confirm` などのブラウザ標準ダイアログも、OBS で使えない可能性を考えて避けている。OBS で検証した結果ではない

## 保存
- キー: `poko-cosmic-countdown-v1`。URL に `id` を付けたときは `poko-cosmic-countdown-v1:<id>`
- 旧キー `cosmicCountdown.v1` があり新キーが無いときは、読み込んで新キーに保存する(旧キーは残す)。`id` 指定時は引き継がない
- 読み込むときに値を補正する(`scale` は 40〜300、日時が不正な項目は 7 日後 21:00 など)
- 利用者が入れた文字は `textContent` で描画する

## URL パラメータ
| パラメータ | 値 | 動作 |
|---|---|---|
| `id` | `[A-Za-z0-9_-]{1,32}` | 保存キーを分ける。不正値は無視して既定キー |
| `bg` | `transparent` | OBS の外でも市松を出さず透過(設定「背景を透過」ON のとき) |

## 動作の決まりごと
- 当日: 設定した日時から 24 時間はお祝いの文字を表示する。その後、普通の項目は「終了しました」、毎年の項目は翌年のカウントに切り替わる
- 毎年の項目: 2/29 は閏年でない年は 2/28 として数える。設定日時から何年過ぎていても、24 時間を過ぎていない最も早い年に繰り越す
- 進捗バー: 開始から設定日時までのうちの経過。開始点は、普通の項目は追加した時または日時を変えた時、毎年の項目は前回の同じ日時
- 0 秒を通過した瞬間に、そのカードにお祝いの演出を出す(画面を開いた時点で既に当日の項目では出さない)。`prefers-reduced-motion: reduce` では動く演出を止める
- フォントは `fonts/` に同梱する(M PLUS Rounded 1c と、Orbitron を元に名前を変えた CosmicDigits。OFL 1.1)
